# Household

Household (家庭管家) keeps a home's stock, shopping list, chores and meal plan, and tells you when something runs low, expires or falls due. It shows a page and an overview card in Persona, sends a daily reminder, and gives the assistant tools over the same records. The records are kept in their own space, built on the same ontology kernel as [spaces](../spaces/README.md).
