# X

X in Persona, two ways: your own X account through the official X API v2 with your own developer app's keys (mentions in the inbox, an organized digest of your home timeline or lists within a daily post budget), or Grok, the xAI `grok` CLI on the hub machine on your SuperGrok / X Premium+ subscription (no X keys: a digest of the accounts and topics you choose, and live X search). Read-only assistant tools either way.
