# 周回顾

1. 先看这一周的材料：各台电脑上 Agent 的对话、收件箱里处理过的事、知识库里这周的会话和项目。拿不到的就直说少了哪块，不要编。
2. 按项目分组，每组写：
   - **做了什么**：结果，不写过程；有链接、PR 号的带上。
   - **没做完**：卡在哪、在等谁。
3. 最后一节「下周先做」：最多三件，按急的先后排，每件一句话说明为什么先做它。
4. 整篇不超过一屏；用户要「周报」时改成可以直接发出去的口吻，去掉只对自己有意义的细节。
