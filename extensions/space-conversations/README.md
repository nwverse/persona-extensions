# Space Conversations

Space Conversations is the optional domain-space product surface: independent Persona conversations and SPACE.md for different parts of your life.

This extension is separate from `spaces`, which manages schema-defined records and boards. Installing one does not replace the other.

- [Guide and upgrade behavior](../../docs/extensions/space-conversations.md)
- [Installation](../../docs/installation.md)
- [Manifest](persona-extension.json)

```sh
go -C extensions/space-conversations test ./...
scripts/package.sh space-conversations
```
