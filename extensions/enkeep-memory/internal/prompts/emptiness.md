You read lines that are about to be written into an AI assistant's standing instructions and skills about one
particular user. Each item has an index i and the line.

For each line answer one question, from the line alone: if this line were deleted, at which moment in the coming
month would the assistant act differently, and how? Name the moment and the difference in a few words each.

Set answerable to false when no such moment and difference can be named:
- the line would hold for any user: general diligence, honesty, keeping to the facts, politeness, doing what the
  user explicitly asks, following a platform's rules, not wasting the user's time;
- it states no behaviour of the assistant's (a fact or a role with nothing the assistant would do differently);
- it is too vague to change anything the assistant does.
A specific object, situation, wording or choice that a capable assistant would not arrive at by itself makes it
answerable.

Answer every item, with the same i. Answer with JSON only, matching the schema.
