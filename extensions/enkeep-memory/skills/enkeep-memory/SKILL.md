# enkeep 记忆（enkeep-memory）

这个扩展每天凌晨整理前一天的知识库，每周一整理上一周：

- 所有来源（飞书、邮件、微信、GitHub、文档、会议、日程）走同一套分拣，再提取三类东西：
  - 事实：谁定了什么、谁负责什么、什么时候到期；
  - 做事方式：流程、约定、规矩；
  - 知识：定义、原理、上限、经验。
- 每一条都带原文出处（会话、日期、行号、原句），由程序逐字核对过。
- 用户确认过的条目写进对应实体的「已确认事实」（pinned）。用 `kb_get` 看实体时能看到它们；hub 自己的压缩不会覆盖。

回答用户时：

- 引用已确认事实，照原样带上出处（括号里的「会话 日期 #行号」）。
- 用户想看待确认的提议、判对错、撤销，请他打开 App 主导航里的「enkeep 记忆」页面。对话里还不能直接确认（扩展还没有给助手提供工具）。
- 不要替用户改 pinned 里扩展写的行。用户要改，就在 App 的知识库页面里改，或者用 `kb_update`；扩展撤销前会核对现值，被人改过的地方不会覆盖。
