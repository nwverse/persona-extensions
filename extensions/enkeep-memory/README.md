# enkeep memory (enkeep-memory)

Keeps the user's memory and curates the Persona knowledge base every day and every week. All sources go through one triage. From what is admitted, it extracts facts, practices and knowledge, each with a citation that a program checks against the original line, and builds an entity–relation graph. It also keeps what the user holds (principles, guidelines, experiences, how they are, facts): every sentence is judged by its setting and how it was said, and a confidence that grows with independent occurrences and decays with time decides what is active and how the assistant gets to see it. Every change to the knowledge base is a proposal that you accept, and every accepted change can be undone. For the first two weeks it only proposes and never writes.
