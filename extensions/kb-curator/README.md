# Knowledge curator (kb-curator)

Curates the Persona knowledge base every day and every week. All sources go through one triage. From what is admitted, it extracts facts, practices and knowledge, each with a citation that a program checks against the original line. It also builds an entity–relation graph. Every change to the knowledge base is a proposal that you accept, and every accepted change can be undone. For the first two weeks it only proposes and never writes.
