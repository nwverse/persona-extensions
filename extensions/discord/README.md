# Discord

Connect Discord to Persona through your own bot: the channels, threads and forum posts it can read go into the knowledge base, and the assistant gets read-only Discord tools. It sends nothing. The bot token stays encrypted on the hub.

- [Extension guide: setting up the bot, what is read, network and limits](../../docs/extensions/discord.md)
- [Installation](../../docs/installation.md)
- [Development and tests](../../docs/development.md)
- [Manifest](persona-extension.json)

The tool descriptions in [prompts/mcp/](prompts/mcp/) are runtime assistant input.
