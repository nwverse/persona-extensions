# Telegram

Connect your own Telegram account to Persona: conversations, inbox, knowledge-base archives, assistant tools and the `tg` CLI. Credentials stay encrypted on the hub; writes require confirmation by default.

- [Extension guide, login, network requirements and CLI reference](../../docs/extensions/telegram.md)
- [Installation](../../docs/installation.md)
- [Development and tests](../../docs/development.md)
- [Manifest](persona-extension.json)

The shipped [Telegram skill](skills/telegram/SKILL.md) is runtime assistant input and keeps its original language.
