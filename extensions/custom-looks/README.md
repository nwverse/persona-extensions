# Custom looks (自建形象)

Five avatars for Persona, as a looks extension: Claude, GPT, 包包, 大肥鱼 and 奶娃, each with its picture, colors and an animated status dot for every state. After installing, pick one in Settings › 形象 (Avatar). Declarative: images and a manifest, no program, settings or credentials.
