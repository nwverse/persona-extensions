# 高德地图（amap 工具）

用的是用户自己在高德开放平台申请的 Key，数据来自高德。

## 坐标

所有工具的坐标都是 **WGS-84「纬度,经度」**，和 `phone_location_current`、`phone_maps_*`、常用地点（`amap_places`、`list_places`、`save_place`）是同一个坐标系。坐标在这些工具之间直接传，不要自己换算成 GCJ-02（扩展内部会换）。

## 先拿到起点、终点或中心点

1. 用户说「附近」「我这儿」「从这里」：先用 `phone_location_current` 拿当前位置（要用户把 Persona 打开在前台），再把坐标传给 `amap_nearby`、`amap_route`、`amap_distance` 或 `amap_static_map`。
2. 用户说「家」「公司」「单位」或自己命名的常用地点（如「回家要多久」「从家到公司」「公司附近」「家天气」）：
   - 可以**直接**把「家」「公司」或别名（`home` / `work` / `office`）/ 自定义名字填进 `amap_route`（`from` / `to` / `waypoints`）、`amap_nearby`（`place`）、`amap_distance`、`amap_static_map`、`amap_weather`（`city`），扩展会自动解析用户在 `设置 › 扩展 › 高德地图` 或「高德地图 › 常用地点」页面保存的地址或坐标。
   - 想先确认用户存了哪些常用地点、或者想看坐标/详情时，先用 `amap_places`（不花高德额度）。
   - 如果 `amap_places` 里还没配过，再用 `list_places` 查 Persona 通用常用地点；都没有就问用户在哪儿，并提醒可以在 `设置 › 扩展 › 高德地图`、「高德地图 › 常用地点」页面配置，或由你用 `save_place` 存下来。
   - 例：「看看现在回家要多久」→ 先用 `phone_location_current` 拿当前位置，再调用 `amap_route(from_latitude, from_longitude, to="家")`；若高德扩展里还没存「家」，查 `list_places` 或问用户。
3. 用户说的是店名、景点、车站：可以直接把名字给 `amap_route` 的 `from` / `to` / `waypoints`，或先用 `amap_search` 找到再用它的坐标。门牌地址用 `amap_geocode`。
4. 同名地点很多（人民广场、万达广场、火车站）：知道在哪个城市就传 `city`。工具的回答会在名字后面写上它找到的城市和区，不对就加上 `city` 再查一次，或者问用户。

## 用哪个工具

- 查高德已配/已存的常用地点：`amap_places`（只读、不花高德额度，查「家」「公司」或用户自定义地点；没配时再查 `list_places`）。

- 找地点：`amap_search`（按名字、品牌、类别，可以指定城市）。
- 联想补全：`amap_input_tips`（用户只记得简称或模糊名字时，快速列出候选地名、区县、adcode 和坐标）。
- 看附近：`amap_nearby`（由近到远，带距离，`keywords` 写要找什么）。
- 地址和坐标互查：`amap_geocode`（地址 → 坐标）、`amap_reverse_geocode`（坐标 → 地址和附近地点）。
- 行政区划：`amap_district`（查省/市/区县/街道层级、adcode、区号和中心点）。
- 路线：`amap_route`。`mode` 选 `driving`（默认）、`walking`、`cycling`、`ebike` 或 `transit`。
  - 驾车顺路经过多个地点时给 `waypoints`（最多 16 个，支持地名、地址或 WGS-84「纬度,经度」，仅 `driving` 支持）。
  - 问「打车多少钱」用 `driving`，看「打车约 ¥」。
  - 问「坐地铁 / 公交怎么走」用 `transit`，给 `alternatives` 2 或 3，让用户挑。出发时间不是现在就给 `depart_at`。
  - 只算路线，不开导航；用户要导航时用 `phone_maps_navigate` 打开地图。
- 批量比距离/耗时：`amap_distance`（一次比较最多 20 个起点到同一终点的驾车/步行/直线距离和耗时，可按 `distance` 或 `duration` 排序，适合挑「最近的店 / 最快的路线起点」）。
- 静态地图：`amap_static_map`（生成 PNG 静态地图图片，可标中心、最多 10 个 A/B/C… 标注点、2–20 个点的蓝色连线，以及 `traffic: true` 实时路况）。
- 天气：中国城市用 `amap_weather`（实况加最多 4 天预报）；境外城市用其他天气工具。

中国境内的地点、营业时间、评分和公交换乘，高德比 `phone_maps_*` 详细；境外的地点用 `phone_maps_*`。

## 额度

- 用户的 Key 额度有限，尤其是搜索（每月几千次）。不要为同一个问题换着说法反复搜，也不要一页一页翻；搜不到就问用户更具体的名字。
- 工具说「额度用完了」时，照它的话告诉用户什么时候恢复、哪些工具还能用，不要重试。
- 工具说 Key 有问题时，请用户到 设置 › 扩展 › 高德地图 换 Key。不要让用户把 Key 发在对话里。

## 回答

- 距离、时长、费用照工具给的数字说。打车费、过路费是高德的估算，会随时段和路况变。
- 跟用户说地名和地址，不要把坐标念给用户。
- 用户的位置和搜索词会发给高德；用户问起隐私时如实说。
