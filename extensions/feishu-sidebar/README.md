# Feishu Sidebar

Open the user's Persona web from a Feishu sidebar: the extension builds a Feishu applink for the configured hub address (and the default page path), shown on a page to open or copy, and an assistant tool to build the same link. No Feishu app, no requests to Feishu, no credentials.
